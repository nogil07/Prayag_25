# PRAYAG 2025

**Inspire Ideas, Ignite Future**

This repository contains the source code for the official website of PRAYAG 2025, a National Level Tech Fest organized by the Department of Artificial Intelligence & Data Science at Adi Shankara Institute of Engineering and Technology.

## About

PRAYAG 2025 is a platform for students to showcase their technical skills and creativity. The event features a variety of technical competitions, workshops, and exhibitions.

## Technologies Used

*   HTML5
*   CSS3
*   JavaScript
*   [particles.js](https://vincentgarreau.com/particles.js/)

## Project Structure

The project is a static website with the following structure:

```
.
Prayag_25/
├── automation_bootcamp.html
├── capture_the_flag.html
├── code-conquest.html
├── contact_pg.html
├── cryptic-codex.html
├── da-vinci.html
├── event_slider_pg.html
├── exhibition.html
├── fun-zone.html
├── gallery_pg.html
├── idea-pitch.html
├── index.html
├── landing_pg.html
├── schedule_pg.html
├── virtual-victory.html
├── coordinator_img/
├── event_images/
├── images/
├── public/
├── rules_event/
├── sponsors/
└── static/
    ├── script/
    └── style/
```

*   **HTML files:** Each HTML file represents a different page of the website.
*   **coordinator_img/, event_images/, images/, public/, sponsors/:** These directories contain the images, videos and other assets used in the website.
*   **rules_event/:** This directory contains the rulebooks for the events.
*   **static/:** This directory contains the CSS and JavaScript files.

## How to Run

To run the website, simply open the `index.html` or `landing_pg.html` file in your web browser.
